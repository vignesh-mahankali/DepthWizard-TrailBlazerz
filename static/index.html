DepthWizard Production Hosting Suite

Enterprise deployment options for running DepthWizard on Cloud, Local, or Hugging Face

Deploy DepthWizard with container isolation, multi-stage caching, and CPU/CUDA auto-detection:

# 1. Build and launch container in background docker compose up -d --build # 2. Access your workstation http://localhost:8000

See Dockerfile and docker-compose.yml in your project root.

Share DepthWizard publicly over high-speed HTTPS with zero port forwarding using Cloudflare Tunnel:

# Run instant free Cloudflare Tunnel script python deploy_tunnel.py

Or run directly with Cloudflared: cloudflared tunnel --url http://127.0.0.1:8000

Host on Hugging Face Spaces for 24/7 free community access with optional ZeroGPU:

1. Create new Space on huggingface.co/spaces (Select 'Docker' SDK) 2. Add your repository files (server.py, depth_engine.py, static/, etc.) 3. Push to Hugging Face Git remote - Spaces builds and serves automatically!

Refer to HOSTING_GUIDE.md for step-by-step instructions.

Production systemd service configuration for Ubuntu / Debian servers:

[Unit] Description=DepthWizard AI GIS Workstation After=network.target [Service] User=ubuntu WorkingDirectory=/opt/depthwizard ExecStart=/opt/depthwizard/venv/bin/uvicorn server:app --host 0.0.0.0 --port 8000 --workers 2 Restart=always [Install] WantedBy=multi-user.target
